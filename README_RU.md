# Pine Script Reference Wiki · v1–v6

Статическая двуязычная (RU/EN) справочная вики по Pine Script v1–v6. Сборка не требует внешних библиотек, сборщика и серверной части.

## Запуск

Распакуйте архив и в папке `pine-wiki` выполните:

    python -m http.server 8000

Откройте http://localhost:8000/ . Прямые ссылки работают: `?v=6&lang=ru&id=<id карточки>`, `?q=`, `?category=`, `?page=`. Версии загружаются по требованию (первая загрузка около 8 МБ). Кнопка «Скачать каталог» выгружает JSON выбранной версии.

## Состав

| Файл | Назначение |
|---|---|
| `index.html`, `wiki-app.js`, `wiki-search.js`, `wiki-compare.js`, `wiki-i18n.js`, `*.css` | интерфейс, поиск, сравнение версий, строки RU/EN |
| `catalog-v1.js … catalog-v6.js` | каталоги версий (карточки, тексты на двух языках, источники) |

| `tools/verify_catalog.py` | проверка целостности и инвариантов (только стандартная библиотека) |
| `tools/e2e_smoke.py` | браузерная проверка по HTTP (нужен `playwright`) |
| `pine-result-less-functions.md` | отдельный отчёт по функциям без раздела «Returns» в источнике (справочный, интерфейс его не использует) |

## Что исправлено в этой сборке

- **История.** Удалено 208 семейств, на которые не ссылалась ни одна карточка; перекрёстные ссылки на удалённые семейства перенаправлены (все ссылки разрешаются). Осталось 1 292 семейства, все используются.
- **Описание результата.** Три пустых описания (`floor` в v3 и v4, `cross` в v3) восстановлены по соседней версии с пометкой и ссылкой на донора. Теперь у всех функций и методов v3–v6 результат описан, причём способ указан в карточке: из источника, «void» по сигнатуре, общее описание функции или описание соседней версии.
- **Типы параметров.** Для 92 параметров без типа (v1–v5) показаны подсказки из соседних версий, визуально отделённые от подтверждённых типов; сами `types` не изменены. Восемь устаревших параметров `transp` в v5 помечены как отсутствующие в текущей сигнатуре.
- **Поиск.** Поисковые термины расширены у 3 155 записей (русские и английские названия объектов, например «бокс», «таблица», «сделки»). Ранжирование учитывает название, синонимы, тему и текст; приоритет у 46 скользящих средних задан данными (`search_rank`), а не запросом в коде. Короткий запрос `sma` не совпадает с `small`.
- **Примеры.** К карточкам без реального примера добавлены 91 указатель на официальную документацию (23 с вызовом в коде, 68 только упоминание; один источник вторичный и помечен) и 766 схематических шаблонов вызова. Указатели и шаблоны не считаются примерами: фильтр «только с примерами» и счётчики учитывают только сохранённые реальные примеры.
- **Качество шаблонов.** В 71 шаблоне заменены условные подстановки: 32 вида `<id>`, `<source_a>` на конкретные значения, 39 вырожденных (`ta.macd(close, 1, 1, 1)`, `ta.stoch(close, close, close, 14)`, `time_close("text", …)`) на типичные.
- **Манифест.** SHA-256 и размеры обновлены после последних правок (`revision: 2026-10-16.final`).

## Проверка

    python tools/verify_catalog.py     # целостность, инварианты, строки интерфейса, node --check
    python tools/e2e_smoke.py          # 27 браузерных проверок по HTTP, ошибок консоли и сети нет

## Известные ограничения

- В источниках v3/v4 нет сведений об обязательности аргументов: 349 из 349 и 755 из 758 параметров остаются со статусом «не указано».
- В v1 и v2 исторические источники неполны (это отмечено в интерфейсе); элементы, отсутствующие в сохранённом снимке (например, `mfi` и `wpr` в v3), не достраивались.
- Схематические шаблоны не компилировались в Pine Editor. Указатели составлены по просмотру страниц документации 16.10.2026; код с них не копировался.
- Часть кратких описаний результата заимствована из общих описаний функций, потому что раздела Returns в источнике нет. Это не замена официальной спецификации.
- Один параметр (`array.from`, `..args` в v4) не имеет ни типа, ни подсказки.
- 295 текстов v6 (редакторские переводы и краткие пояснения) не имеют машинно проверяемого происхождения; они помечены как редакторские.
- Содержимое не сверялось повторно с живыми страницами TradingView.
